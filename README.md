# 意外險保障試算報價系統（富邦人壽 南方通訊處）

富邦人壽 南方通訊處 共用的意外險試算工具。靜態網站（GitHub Pages），開啟 `index.html` 即可使用。

- 五項商品：OLA6 金來寶小額終身壽險（主約）、ADG、TMR、ADM、ADH（骨力勇），依民國生日計算保險年齡、職業類別、繳別即時試算。
- 費率與計算邏輯沿用原版工具（`js/rates.js` 原封不動；`js/app.js` 前段計算函式未修改）。
- 骨折／脫臼給付比例圖（點選部位即時試算）。
- **業務員資料**：頁面最上方填寫姓名／職級／電話（只存在自己的瀏覽器，localStorage `nf-agent-profile-v1`，與南方通訊處旅平險報價工具 https://toperic1836.github.io/travel-quote/ 共用，填一次即可）；客戶頁連結、保障彙整圖、頁尾署名都會顯示填寫的業務員，品牌固定為「富邦人壽 南方通訊處」。未填寫時只顯示「富邦人壽 南方通訊處」。
- 新增：客戶頁連結（`#q=`，唯讀，含業務員資料）、下載保障彙整圖（PNG）、自動保存草稿（`nf-acc-quote-draft-v1`）、恢復預設、旅平險報價連結。
- 本頁為試算，實際以富邦人壽核保、保單條款與正式文件為準。
